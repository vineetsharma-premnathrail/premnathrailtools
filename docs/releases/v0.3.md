# Release v0.3 — Module Expansion

**Module:** Release Notes
**Prepared by:** Vineet Sharma
**Date:** 29 August 2026
**Covers:** 2026-08-21 (`22f490e`, "update as version 0")

---

## 1. Summary

The largest single expansion of the portal's module footprint to date.

This release adds four new business modules — **HR, Design, Electrical, and Store** — alongside a standalone backend Vendor module, a database-backed Module registry, and foundational RFQ/Purchase Order structures for the P2P pipeline.

`AVAILABLE_APPS` grows from five modules to nine.

---

## 2. What Shipped

### 2.1 New Modules

* **HR** — Employee directory and organizational chart built around the existing `User` model, including reporting manager, date of joining, designation, and department. HR is not a payroll or attendance system.
* **Design** — Engineering document management tied to projects, including document upload, versioning, and discipline/document-type tagging through SharePoint.
* **Electrical** — Project-based work-order tracking with auto-numbered work orders using the `EWO-{year}-{seq}` format, assignment, status, and priority.
* **Store** — Inventory management with stock-item catalog, storage locations, transaction history, and calculated on-hand quantities.
* **Vendor** — Backend vendor management with category, status, and qualification status. Vendor functionality is accessed through Purchase rather than exposed as an independently assignable application.

### 2.2 Module Registry

* Added a database-backed `Module` table containing key, label, icon, description, active status, and sort order.
* The registry drives the module checklist displayed in Users & Roles.
* Module display metadata can therefore change without requiring a frontend deployment.
* `AVAILABLE_APPS` remains the actual authorization boundary; the registry provides display metadata only.

### 2.3 P2P Pipeline

* Added Purchase Order tables.
* Added RFQ tables.
* Added stock-item relationships to P2P request items.
* These structures establish the foundation for the later RFQ → Purchase Order workflow.

### 2.4 CRM

* Added quotation detail tables.
* Added quotation line-item tables.
* These models provide the data foundation for the quotation PDF export introduced in v0.5.

### 2.5 Platform

* Extended Alembic migrations for:

  * Module registry
  * HR profile fields
  * Quotation details and line items
  * Engineering documents
  * Vendors
  * Electrical work orders
  * P2P purchase orders
  * Store tables
  * RFQs
  * P2P stock-item links
* Removed CRM bulk-import routes.
* Removed the separate Notes model and routes, consolidating that functionality elsewhere in CRM.

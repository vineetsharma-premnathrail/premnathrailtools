# Release v0.6 — Technical Offer, CRM Products, and the 50-Document Checklist

**Module:** Release Notes
**Prepared by:** Vineet Sharma
**Date:** 29 August 2026
**Covers:** 2026-08-27 (`ea969b0`, `f9149b3`, `4bd2ac1`)

---

## 1. Summary

CRM gains a Technical Offer Request workflow with Word and PDF generation, sent from the acting user's own mailbox. It also gains Products and Payment Terms catalogs and quotation enhancements.

P2P/Purchase Orders gain additional approval-role support, while the project's documentation set is substantially expanded to complete the 50-document checklist. The release also includes a UI polish pass.

---

## 2. What Shipped

### 2.1 CRM — Technical Offer

* Added Technical Offer Request generation in both Word (`technical_offer_docx.py`) and PDF (`technical_offer_pdf.py`) formats.
* Added a dedicated Technical Offer viewer at `/dashboard/crm/technical-offer/[id]`.
* Technical Offer Request emails are sent from the acting user's own mailbox rather than a fixed service account.
* Added `technical_offer_number` and `technical_offer_date` to quotations.
* These fields are pre-filled from the inquiry's technical offer when creating a quotation.
* Updated quotation PDFs to use **QUOTATION** and **CLIENT** instead of **QUOTE** and **BILL TO**.
* Quotation PDFs display the technical offer number and date when available.
* Corrected the capitalization of **Valid Until** and **Delivery Time** labels.
* Technical Offer Request PDFs use an in-app protected viewer/document ID instead of directly exposing the raw SharePoint URL.

### 2.2 CRM — Products & Payment Terms

* Added a CRM Products catalog with dedicated routes and schemas.
* Added a Payment Terms catalog with dedicated routes and schemas.
* Added discount-condition fields to CRM quotations.
* Added project-detail fields to CRM Inquiries.
* Added `quot_number_base` to quotations.

### 2.3 P2P / Purchase Orders

* Added Purchase Order approval-role support.
* Continued the approval-role architecture introduced in v0.5.

### 2.4 Platform & UI

* Added a reusable iOS-style Checkbox component for application-wide use.
* The component is used in areas including Users & Roles approval-role and permission controls.
* Refreshed card, tab, input, and section hover states.
* Updated the Dashboard background gradient.

### 2.5 Documentation

Expanded the project documentation set to complete the 50-document checklist, including:

* Project Charter
* Business Requirements Document
* Product Requirements Document
* Scope Statement
* Risk Register
* Project Plan / Tracker
* Threat Model
* Low-Level Design
* Test Report / Test Cases
* Versioning Policy
* Dependency Inventory
* Monitoring Plan
* Disaster Recovery Plan

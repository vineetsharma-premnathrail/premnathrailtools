# Release v0.7 — Stop Leaking Raw SharePoint URLs

**Module:** Release Notes
**Prepared by:** Vineet Sharma
**Date:** 29 August 2026
**Covers:** 2026-08-29 (`c6ba3ab`)

---

## 1. Summary

A security-focused release that removes direct exposure of raw SharePoint `webUrl` values from attachment responses and replaces client-side SharePoint access with backend-proxied content endpoints.

The release also introduces signed, time-limited document links for external Technical Offer recipients and fixes a Teams notification threading issue.

---

## 2. What Shipped

### 2.1 Security — Attachment URLs

* All attachment viewing and downloading now goes through backend-proxied `/content` endpoints.
* Added the reusable `useAttachmentBlobUrl` frontend hook for attachment access.
* Removed direct `<img src>` and `<a href>` usage of raw SharePoint URLs.
* `sharepoint_url` is no longer serialized in API responses.
* Technical Offer Request emails now use self-issued, signed, time-limited, single-document tokens for external document access.
* External document access no longer depends on SharePoint's native sharing configuration.

### 2.2 Fixes

* Teams push notifications no longer block request threads; notification delivery now runs through a background thread pool.
* Fixed the `broadcast_notification` `app_name` bug in the CRM module.

---

## 3. Security Impact

This release closes the attachment-access gap in which raw SharePoint `webUrl` values were exposed to clients.

The portal now acts as the access boundary for attachment content:

**Client → Portal `/content` endpoint → SharePoint**

rather than:

**Client → Raw SharePoint `webUrl`**

This keeps SharePoint URLs out of API responses and prevents attachment access from depending on direct SharePoint URL visibility.

---

## 4. Relationship to Previous Releases

This release extends the protected-access pattern introduced for Technical Offer PDFs in v0.6 (`f9149b3`).

Where v0.6 protected Technical Offer documents specifically, v0.7 applies the backend-proxy approach across attachments in:

* ERP
* CRM
* P2P
* Purchase
* Design

The external Technical Offer sharing flow is documented separately in **ADR 0004: Self-Issued Signed Document Links Instead of SharePoint's Native Sharing Links**.
